# Huntress SOC Platform Trial

A working log from a live trial of the Huntress Managed Security Platform
(EDR, ITDR, SIEM, ISPM, SAT). This is hands-on evidence for a security
analyst career path, built inside the actual product instead of a
simulated range.

Notes are organized by platform module, one folder per capability, added
as the trial happened.

## Modules

| Folder | Covers |
|---|---|
| `EDR/` | Endpoint detection: footholds, malicious process behavior, lateral movement, ransomware precursors |
| `ITDR/` | Identity threat detection: M365/Entra account takeover, BEC, unwanted access rules |
| `SIEM/` | Log ingestion and ES\|QL search across endpoints, firewalls, cloud, and SaaS |
| `ISPM/` | Identity security posture: M365/Entra misconfiguration scanning |
| `SAT/` | Security awareness training: phishing simulation and reporting |

## Trial window

The EDR, ITDR, SIEM, and ISPM trial ran through 2026-08-03. SAT ran
through 2026-08-10.
